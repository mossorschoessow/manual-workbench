# 設備維修手冊工作臺

給醫院設備維護人員用的手機應用：輸入設備型號，馬上打開對應的維修手冊。
純網頁技術（PWA），**在安卓 Chrome 上安裝到主畫面後可完全離線使用**，手冊存在手機本機，不上傳任何伺服器。

**📱 安裝網址：<https://mossorschoessow.github.io/manual-workbench/>**
用安卓 Chrome 打開 →「⋮」→「安裝應用」。

## 功能

| 功能 | 說明 |
|---|---|
| 型號查詢 | 忽略大小寫、空格、橫線、斜線、全形半形；`ip 3000`、`IP-3000`、`ip3000` 都能找到；打錯 1–2 個字符也能找到相近型號 |
| 一書多型號 | 一本手冊可綁定多個型號，查任何一個都能找到 |
| 內置 PDF 閱讀器 | 分頁懶加載（幾百頁的手冊也不卡）、雙指縮放、雙擊放大、跳頁 |
| 手冊內搜索 | 搜故障代碼（如 `E03`），列出所在頁和上下文，跳轉後高亮命中位置 |
| 掃碼查詢 | 用相機掃設備上的條碼 / 二維碼直接查詢（Android Chrome 支持） |
| 其他格式 | 圖片在應用內查看；Word、Excel 等通過「用其他應用打開」交給 WPS / Office |
| 收藏、最近查看 | 常用設備一鍵直達 |
| 批量導入 | 一次選多個文件，按文件名自動識別型號 |
| 備份 / 遷移 | 整個手冊庫導出成一個 `.manlib` 文件，換手機時恢復 |
| 多語言 | 繁體中文、简体中文、English、日本語、한국어、Español、Français、Deutsch、Русский、Tiếng Việt |

## 語言

首次打開時按手機系統語言自動選擇（中文會區分繁體 / 簡體），也可在「設置 → 語言」手動切換，選擇會保存在這部手機上。語言標題旁始終帶英文 “Language”，誤選了看不懂的語言也能找回來。

- 翻譯都在 `i18n.js`。新增語言：在 `LANGS` 加一項，再複製一份字典翻譯即可；缺少的詞條會自動顯示英文。
- 除中文和英文外，其他語言是機器輔助翻譯，正式給外語使用者前建議請母語同事過目。
- 安裝後桌面圖示下的名字來自 `manifest.webmanifest`，固定為中文「維修手冊」，不隨應用內語言改變。

## 部署（必須通過 HTTPS 或 localhost 訪問）

離線緩存、相機掃碼都要求安全連接，所以不能直接在手機上雙擊打開 `index.html`。把整個 `manual-app` 文件夾放到任意靜態網站空間即可，**不需要後端、不需要資料庫**：

- **最快**：打開 <https://app.netlify.com/drop>，把 `manual-app` 文件夾拖進去，得到一個 https 網址。
- **GitHub Pages / Cloudflare Pages / Gitee Pages**：上傳文件夾內容即可。
- **醫院內網**：放到任何內網 Web 伺服器（IIS、Nginx 等）。內網需要配置 HTTPS 證書，否則離線和掃碼功能不可用。

文件夾已包含 PDF.js 及中文字體映射表（`vendor/pdfjs`），不依賴外網 CDN，在無外網的內網也能正常工作。

## 手機上安裝

1. 用 **Chrome** 打開部署後的網址。
2. 點右上角「⋮」→「安裝應用」或「加到主畫面」。
3. 之後從桌面圖示打開，像普通 App 一樣全屏使用，沒網也能用。

## 錄入手冊

- **單本**：「手冊庫」→「新增手冊」→ 選文件、填型號（多個用逗號分隔）、品牌、設備名稱、科室。
- **批量**：「設置」→「批量導入」。文件名按 `型號1,型號2__標題.pdf` 命名可自動識別，例如：
  - `Dash4000,Dash5000__GE監護儀維修手冊.pdf`
  - `IP-3000__輸液泵維修手冊.pdf`
  
  文件名中沒有 `__` 時，整個文件名作為型號，導入後在手冊庫中點鉛筆圖示再修改。

**建議做法**：在一部手機上整理好全部手冊 → 導出備份 → 把 `.manlib` 文件發給其他同事 → 各自「從備份恢復」。

## 注意事項

- 資料存在手機瀏覽器的本機存儲。**清除 Chrome 的網站資料會刪除所有手冊**，請定期導出備份（設置頁會顯示上次備份日期）。
- 安裝到主畫面後，Chrome 一般會把存儲標記為「持久」，不會因空間不足被自動清理；設置頁可查看狀態。
- 掃描版 PDF（整頁是圖片）無法進行文字搜索，型號查詢不受影響。
- 修改了應用代碼後，把 `sw.js` 裡的 `CACHE` 版本號加 1，手機下次聯網打開時會自動更新。手冊資料不受更新影響。

## 文件結構

```
manual-app/
├── index.html            頁面結構
├── style.css             樣式（自動適配深色模式）
├── i18n.js               多語言字典與切換
├── app.js                全部邏輯：存儲、搜索、閱讀器、備份
├── sw.js                 離線緩存
├── manifest.webmanifest  安裝到主畫面的設定
├── icons/                應用圖示
└── vendor/pdfjs/         PDF.js 3.11.174（Apache-2.0）
```
